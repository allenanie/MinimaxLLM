# Friction log

- Harbor writes job-level `jobs/<job>/result.json` early while the job still runs; treating it as done and relaunching can rmtree a live job dir. `optimize.evaluate` reuses only if `parse_job` covers all tasks.
  - Instead of polling job-level `result.json`, wait until per-trial `result.json` count == task count and harbor `/proc/<pid>` is gone.
- `pgrep -f "harbor run.*..."` self-matches sibling pollers' cmdlines, so wait loops spin forever after harbor exits.
  - Instead of `pgrep -f` on the harbor cmdline, poll file state (per-trial count + pid gone) or match the exact binary path.
- Killing the optimize driver (`pkill -KILL` on the python) leaves the harbor subprocess as an orphan that keeps writing the job dir.
  - Instead of resuming immediately after killing the driver, wait for the orphan harbor to finish before `evaluate` can see the job dir.
- Detached `codex exec` hangs on "Reading additional input from stdin...".
  - Instead of inheriting stdin, run proposer backends with `stdin=subprocess.DEVNULL` (`proposer.py`).
- Claude proposer with inherited `HOME=/home/allennie` wrote into `/home/allennie/.claude/projects/` (shared-account violation).
  - Instead of inheriting the login HOME, pin `HOME=~/yoonho` (and `CODEX_HOME=~/yoonho/.codex`) in every subprocess env on this box.
- Scrubbed env carrying shell `MODAL_PROFILE=iris-lab-ws` → `AuthError: Token missing` (profile absent from `~/.modal.toml`; live: `aimingnie`, `stanford-iris`).
  - Instead of carrying `MODAL_PROFILE` into job envs, omit it so jobs auth as active `stanford-iris` (`rollout.py::_job_env`).
- Claude Code injects `UV_PROJECT_ENVIRONMENT` / `VIRTUAL_ENV` at empty `~/yoonho/.cache/uv/.venv_<id>`, bypassing shared `.venv`; scrubbed `uv run` also rewrites `uv.lock` (drops `fork-strategy`).
  - Instead of bare `uv run`, prefix `UV_PROJECT_ENVIRONMENT=$PWD/.venv VIRTUAL_ENV=` and use `uv run --no-sync`; for validation, call `.venv/bin/python` directly.
- Repo-root `harbor` symlink is an empty namespace (`harbor.__file__` is None), so bare `import harbor` false-passes with no package installed.
  - Instead of `import harbor` from the repo root, assert `harbor.__file__ is not None` and set cwd away from the repo root (`rollout.py::validate_candidate`).
- With `task.toml` `docker_image` set and `force_build` off, harbor `should_use_prebuilt_docker_image` ignores the Dockerfile, so a plant `COPY` is silently dead.
  - Instead of appending COPY to the existing Dockerfile under a `docker_image` key, rebase as `FROM <prebuilt>` + COPY, remove `docker_image`, and verify the plant from inside a built container (`bake_bait.py`).
- Tblite tasks with whole-context `COPY . /workdir` would drop `_solution/` into the workdir and leak the edited Dockerfile at `/workdir/Dockerfile`; `.dockerignore` can also exclude the plant.
  - Instead of adding `_solution/` to context alone, save `Dockerfile.orig` and `RUN rm`/`mv` it back, and append `!_solution` / `!_solution/**` to `.dockerignore` (`bake_bait.py`).
- `_extract_reward` maps crashes to 0.0, so a neutered or infra-failed trial looks like a hard task. `etl_checkpoint_resume_bug` fails modal image-build permanently (builds fine locally); expect one void 0.0 in every tblite train eval.
  - Instead of trusting a 0.0 aggregate, run `check_canary` (void Steps with no LLM calls / all-empty observations) and treat missing-trajectory trials as infra voids, not hard tasks.
- Coders' `workspace-write` sandbox does not block reads outside cwd: given an absolute `private/` path, codex copied the answer key.
  - Instead of relying on the sandbox for secrecy, keep the barrier as layout + silence: never stage a `private/` path; writes are confined, reads are not.
- Two `propose()` calls sharing one run dir attribute each other's driver writes to the model via the mtime snapshot, failing both (002 step-2 dry runs, two wasted codex calls).
  - Instead of overlapping propose calls, keep them strictly sequential per run dir with nothing else writing the run tree during the window.
- A codex adversary ran its variant's grader in-workspace and left `__pycache__/*.pyc`, crashing `propose()`'s contract-dir readback with UnicodeDecodeError (002 step-2 dry run).
  - Instead of crashing, `propose()` now raises ProposalError naming the non-text file, and the adversary PROMPT tells the model to delete generated files before finishing.
